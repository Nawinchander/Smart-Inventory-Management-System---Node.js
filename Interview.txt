nterview Questions and Answers
Q1 Why do we use Service Layer?

Answer

Service layer contains business logic and separates controllers from database logic.

Q2 Why Repository Pattern?

Answer

It abstracts database operations and allows changing MongoDB/MySQL implementation without affecting business logic.

Q3 Why use MongoDB and MySQL together?

Answer

MySQL is suitable for relational data and transactions, while MongoDB handles flexible schemas and high-volume document storage.

Q4 Why Binary Search instead of Linear Search?
Algorithm	Complexity
Linear Search	O(n)
Binary Search	O(log n)

Binary Search is faster for sorted data.

Q5 Why Priority Queue for orders?
Answer

Priority Queue allows urgent orders to be processed first.

Complexity:

Insertion O(log n)
Deletion O(log n)
