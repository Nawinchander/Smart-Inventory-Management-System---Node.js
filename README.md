Smart Inventory System

## Tech Stack

- Node.js
- Express.js
- MongoDB
- MySQL
- Docker
- Kubernetes
- Helm
- Terraform
- Prometheus
- Grafana
- Elasticsearch
- Kibana
- GitHub Actions
