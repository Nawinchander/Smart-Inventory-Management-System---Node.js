4. helm/
helm/
│
├── Chart.yaml
├── values.yaml
└── templates/

Purpose:

Package manager for Kubernetes.

Similar to:

npm → Node.js

Helm → Kubernetes

Without Helm:

50 YAML files.

With Helm:

Templates + Variables.

Example:

Instead of:

replicas: 3

Use:

replicas: {{ .Values.replicaCount }}

which comes from:

replicaCount: 3

inside:

values.yaml

Benefits

Reusable templates
Environment management
Easier deployment
Less duplication
